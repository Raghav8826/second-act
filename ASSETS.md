# Active artwork

The selection menu uses four user-supplied category illustrations: `filmmaker_pop_v3.png`, `theatre_pop_v3.png`, `photography_pop_v3.png` and `fashion_pop_v3.png`. They were edited with the built-in image-generation tool to remove halftone dots while retaining their subjects, palettes and composition, then encoded as optimized PNGs. The same illustrations are reused on the brief screen.

`profile-pop-grid.jpg` is the supplied six-portrait sheet. CSS background positions select each portrait without creating six duplicate files.

`second-act-mark.svg` is the current RGB spotlight brand mark, used for the favicon and interface branding. The opening uses native HTML/CSS/JavaScript rather than a video download. Film-reel movement reuses the existing camera image through clipped SVG layers; no duplicate image assets are required.

Earlier generated artwork prompts and unused lips-intro components are retained in the local-only legacy design archive. They are not needed to run the website.
